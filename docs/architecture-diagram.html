PMTilesRegistry

Workspace Path
src/core/pmtiles/PMTilesRegistry.ts
Architectural Role

Central registry that binds the custom pmtiles:// protocol into MapLibre GL JS and routes tile requests (z/x/y) to the active Source adapter (Remote URL, Browser OPFS File, or Mobile Native File).

How It Works Offline (No Internet)

Reads the 127-byte header and 16 KB root Hilbert directory directly from local disk. Resolves any (z, x, y) tile request to a pure (byteOffset, byteLength) tuple with zero network lookups.

Key API / Pattern
maplibregl.addProtocol('pmtiles', protocol.tile);
const pmtiles = new PMTiles(source);
const header = await pmtiles.getHeader();
protocol.add(pmtiles);

Inside a Single .pmtiles Archive (v3 Spec)

Why a 4 GB country topo map loads instantly with < 10 MB RAM: tiles are ordered along a spatial Hilbert curve and accessed via direct byte offsets.

[Bytes 0 – 126] 127B Binary Header

Magic "PMTiles\x03", tileType (MVT/PNG/WebP), minZoom/maxZoom, Lat/Lon Bounds, Directory Offsets

Read #1 (16 KB)
[Bytes 127 – ~16,384] Root Directory

Maps Hilbert Tile IDs (z/x/y) to exact byte offsets & lengths (cached in RAM on open)

Cached in RAM
[JSON Metadata Block]

Vector layer definitions (roads, trails, contours, water, pois) & map attribution

On Init
[Leaf Directories] (For huge archives)

Sub-directories for high-zoom tiles (z14–z16), fetched on-demand & cached in LRU cache

LRU Cached
[Hilbert-Clustered Tile Payloads] (99% of file)

Individual Gzip MVT vector tiles or Terrarium DEM PNG tiles sliced by exact (offset, length)

~15–45 KB / tile

Where .pmtiles Maps Are Saved & Read

Physical file locations and random-access reading mechanisms across every target platform.

1. Android App (Capacitor Local Storage) NativeSliceSource
/storage/emulated/0/Android/data/com.navapp.outdoor/files/maps/*.pmtiles

Persisted in external/internal app files (never auto-deleted by OS cache cleaner). Read via Java RandomAccessFile.seek(offset) returning HTTP 206 byte streams.

2. Web App / PWA (Browser Persistent Disk) FileSource (OPFS)
navigator.storage.getDirectory() → /maps/israel-hiking.pmtiles

Origin Private File System stores multi-GB archives on disk. Or users pick any local file (C:\Maps\*.pmtiles) with zero copy via file.slice(offset, offset + length).

3. iOS App (Capacitor iOS Target) NativeSliceSource
Library/Application Support/maps/*.pmtiles & Documents/maps/

Marked with NSURLIsExcludedFromBackupKey so multi-GB maps don't fill iCloud. Read via Swift FileHandle.seek(toOffset:) over custom URL scheme.

4. Project Dev & Cloud CDN FetchSource
C:\dev\NavApp\public\assets\maps\*.pmtiles | https://cdn.../map.pmtiles

Bundled starter sample map for local testing or remote cloud object storage (Cloudflare R2 / AWS S3) using standard HTTP Range requests.
