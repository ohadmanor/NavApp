Display

PoiManager.getAllPois() merges db.pois, offroadPoisCache (or-* from Israel.pois.geojson), and db.poiOverrides, suppressing deleted: true records.

  • GeoJSON source israel-pois-src renders across 3 zoom-tiered layers: israel-pois-peaks, israel-pois-midzoom, and israel-pois-labels.
  • Vector POIs in POI_STYLE_LAYER_IDS are filtered by buildVectorPoiLayerFilter (name required + deletedSignatures exclusion).

Add / Update

User-created POIs (user-poi-*) are saved locally in db.pois and synced to Firestore based on visibility.

  • Private or shared POIs sync via PrivatePoiCloudService to private_pois.
  • Global POIs sync via GlobalPoiCloudService to global_pois.

Edit

Edits route differently depending on whether the field is shared or personal.

  • Category/subcategory changes on bundled/vector POIs (osm-*, or-*, vt-*) write to db.poiOverrides and sync to poi_overrides.
  • Personal userNotes stay local in db.pois and are preserved during global syncs.

Delete

Deletes either remove the document or record a tombstone override.

  • user-poi-*: removed from db.pois and deleted from private_pois or global_pois.
  • Bundled/vector POIs: marked { deleted: true } in db.poiOverrides / poi_overrides and added to deletedPoiExclusionMultiPolygon.
